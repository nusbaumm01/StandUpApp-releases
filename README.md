# Stand Up — downloads

Stand Up is a small tray / menu bar app for macOS and Windows that reminds you
to stand up once an hour. It pops up "Time to stand up" (with Snooze), runs a
15-minute stand timer, then tells you when you can sit down. The reminder
interval, stand time and snooze length are adjustable in Settings.

This repository only holds the downloads. Get the newest version from the
[latest release](https://github.com/nusbaumm01/StandUpApp-releases/releases/latest).

## Which file to download

| Your computer                        | File                              |
| ------------------------------------ | --------------------------------- |
| Mac with Apple silicon (M1 or later) | `StandUp-<version>-macos-arm64.zip`   |
| Mac with an Intel processor          | `StandUp-<version>-macos-x64.zip`     |
| Windows PC (most PCs, Intel / AMD)   | `StandUp-<version>-windows-x64.zip`   |
| Windows on Arm (Snapdragon)          | `StandUp-<version>-windows-arm64.zip` |

Nothing else needs to be installed.

## First run

The app is not signed with a paid developer certificate, so the system warns
you the first time you open it.

**Mac:** unzip, drag `Stand Up.app` into Applications and open it. When macOS
refuses, go to System Settings → Privacy & Security and click **Open Anyway**.
The app appears in the menu bar only, as a green circle with a white arrow.

**Windows:** unzip and double-click `StandUpApp.exe`. On the blue "Windows
protected your PC" box, click **More info**, then **Run anyway**. The icon
appears in the notification area, possibly under the `^` arrow.

## Using it

Click the icon for the menu: **Stand up now**, **Pause / Resume**,
**Settings…** and **Quit**. Settings are stored on your own computer and the
app does not use the network.
